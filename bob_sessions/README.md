## How to Export Sessions

1. In IBM Bob IDE, navigate to completed tasks
2. Select "Export Task Session"
3. Save reports as markdown files in this directory
4. Take screenshots of key interactions
5. Name files descriptively: `YYYY-MM-DD-task-name.md`

## Example Session Report Structure

```markdown
# Task: [Task Name]
Date: YYYY-MM-DD
Duration: X hours

## Objective
[What was the goal]

## Bob's Contributions
- [Specific help provided]
- [Code generated]
- [Problems solved]

## Key Interactions
[Screenshots or conversation excerpts]

## Outcome
[What was accomplished]

## Files Modified
- file1.py
- file2.tsx
```
